            📺 YouTube

            Let your agents upload videos and change your channel's name or description, through YouTube's official API. Every action asks you first, with no “Always allow”.

            1. Open Google Cloud Console and create a project.
            2. APIs & Services → Library: enable YouTube Data API v3.
            3. OAuth consent screen: choose External and add your own Google account as a test user.
            4. Credentials → Create credentials → OAuth client ID, type Desktop app. Paste its ID and secret here.
            Saved only on this PC (data/youtube.json).
